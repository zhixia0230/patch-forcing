# Codex 执行指令：RadioMapSeer DPM 数据划分与可逆 FFT 16 频带分解

请在当前项目中实现并运行以下数据预处理任务，交付可运行代码、固定划分清单、固定频带配置、数据读取接口和验证报告。不要只给方案。当前任务只实现 GT 的划分与分解，不启动模型训练，不自行调整后续异步去噪算法。

研究目标是把同一张 radiomap 表示成从低频到高频的 16 张同尺寸实值子带图，供后续模型采用不同的频带去噪进度。分解采用二维 FFT 径向硬分带，基于训练集统计进行近似等能量划分，保留全部复数频谱信息，允许通过子带求和完整重构 GT。

本指令把用户所说的“训练集还为原来的100”按上下文解释为“测试集仍保留原来的100”。最终为训练600个场景、验证50个场景、测试100个场景，验证集是测试集的子集。这是当前明确要求的临时方案，不要自动改成600/50/50。

3. 明确被分解的GT数值定义

- 本次采用`gt_mode=raw_dpm_01`：若原始DPM为uint8灰度，令`x = raw.astype(float64) / 255.0`。
- 在分解前不进行逐图min-max、不减均值、不转[-1,1]、不加窗、不裁剪、不缩放、不阈值截断、不重新遮盖建筑区域。这样不会改变DC能量，也保留原始DPM像素信息。
- 若现有loader含`thresh`、噪声地板截断或`2*x-1`，本预处理路径必须显式绕过并记录区别。不得把处理后GT冒充原始DPM；后续模型应显式选择对应数据配置。
- 核实RGB/RGBA存储是否只是灰度复制。只有确认灰度通道一致时才能读取单通道；不能随意对不同通道求均值或使用有损转换。
- 非uint8输入必须依据真实编码确定全局可逆缩放并记录，不能直接除255。无法确定编码时报告具体问题。
- 当前实现以核实后的同尺寸方形GT为输入；如实际尺寸异常，报告异常，不通过resize掩盖。

4. 只用新训练集拟合一套固定分带边界

分带统计只读取600个训练场景的全部有效DPM。验证集和测试集不得参与边界拟合、尺度估计或异常阈值学习。所有集合使用同一组固定mask，推理时也直接加载这些mask，不依赖待生成样本的GT计算边界。

对每张训练图i：

```python
F_i = fftshift(fft2(x_i, norm='ortho'), axes=(-2, -1))
E_i = abs(F_i) ** 2
T_i = E_i.sum()
p_i = E_i / T_i  # T_i > 0时
```

然后计算`p_bar = mean_i(p_i)`。采用“每张图先归一为100%，再在训练样本之间求平均”的统计方式，不使用`sum(E_i)/sum(T_i)`替代，因为后者会让高能量样本权重更大。

统计使用float64/complex128、流式累计，不把全部训练图或频谱堆入内存。T_i为零的全零GT不参与能量分布拟合，计数并保存其ID；这些样本仍保留在Dataset中，可正常分解成16张零图。所有训练样本都为零时明确失败。不要向分母随意加常数后声称各图能量恰好归一。

这里的“近似等能量”指训练集平均的能量占比，不是每一张图的16个频带都必须达到相同占比。禁止为每张图单独重新拟合mask。

5. 在FFT平面构造完整的径向壳层

对H=W的方形图，生成与fftshift一致的有符号整数频率坐标：

```python
ky = rint(fftshift(fftfreq(H)) * H).astype(int64)
kx = rint(fftshift(fftfreq(W)) * W).astype(int64)
q = ky[:, None]**2 + kx[None, :]**2
shell_q = unique(q)  # 升序
```

用整数半径平方q分组，避免浮点半径比较误差。同一个q上的所有频点属于同一个不可分割的径向壳层；将相邻壳层合并为频带。

- 不能逐频点排序后切出缺口或扇形，不能拆开同半径壳层，也不能拆开共轭频点。
- 频带从中心向外排序，band_00最低、band_15最高。band_00是中心圆盘，其余是频谱方形网格内的环形区域。
- 必须包含频谱四角，最大半径由整个频谱平面决定。不能只保留内切圆，否则无法完整重构。
- 显式验证Nyquist行/列以及DC等自共轭位置的归属；不要凭“看起来对称”判断mask有效。
- 本次固定采用二值硬mask，不用软重叠mask、平滑过渡窗、小波或其他分解替代。

每个壳层的训练平均能量为`e[j] = p_bar[q == shell_q[j]].sum()`，所有壳层能量之和应约为1。

6. 16频带近似等能量划分：DC例外与离散处理

名义目标是`tau = 1/16 = 0.0625`，但不能通过复制、拆分或缩小频谱系数强行达到该比例。

先检查中心DC壳层的平均占比`p_dc=e[0]`：

- 如果`p_dc > tau`，令band_00仅包含DC壳层。这个频点完整保留，允许其能量超过6.25%。其余15带初始目标为`(1-p_dc)/15`，不是继续要求每带6.25%。
- 如果`p_dc <= tau`，从DC开始，对全部壳层分成16个连续非空频带；band_00可以包含DC和紧邻的低频壳层。
- 判断只基于训练集统计；个别样本DC更大时仍然使用固定mask，不能逐样本改变分带方案。
- 如果过大能量出现在非零半径壳层，保持其径向顺序并完整分配到所在频带，不得把高频点搬进最低频带。

为保证实现明确、可复现，采用以下确定性近似算法，不要求全局最优：

```text
对需要继续划分的壳层后缀，设起始下标为a，剩余频带数为B。
如果剩余壳层数少于B，报错，不创建空mask。

当B > 1：
    E_rem = sum(e[a:])
    target = E_rem / B
    在所有合法终点j中，选择使abs(sum(e[a:j+1])-target)最小的j。
    合法条件：j >= a，且j之后至少保留B-1个壳层。
    若误差完全相同，选择较小的j。
    当前频带包含a到j的全部壳层。
    保存此次target、实际能量和偏差。
    a = j + 1
    B = B - 1

最后一带接收所有剩余壳层，含最外角落。
```

这一算法会在每次整数壳层取舍后，用剩余能量更新后续目标；若单个壳层过大，允许该带超出目标。不得从内部频点裁掉能量来修正偏差。

保存16带实际训练平均占比、半径范围、频点数、壳层数和每次划分偏差。如部分频带偏差较大，报告原因，但不要自动改用等宽分带或修改16这个数量。本次执行已经确定该分解方法。

7. 保留完整复数系数，得到同尺寸实值子带

生成16个二值mask `M[k]`，shape为`[16,H,W]`，满足：

```python
M[k].dtype == bool
M.sum(axis=0) == 1      # 每个频点恰好属于一个频带
M[k].sum() > 0         # 无空mask
```

对每张GT：

```python
F = fftshift(fft2(x, norm='ortho'), axes=(-2, -1))
F_k = M[k] * F
z_k = ifft2(ifftshift(F_k, axes=(-2, -1)), norm='ortho')
# 先验证z_k的虚部只有浮点舍入误差，再取实部
x_k = z_k.real
bands = stack([x_0, ..., x_15], axis=0)  # [16,H,W]
x_recon = bands.sum(axis=0)             # [H,W]
```

FFT、shift、逆shift只作用于最后两维，不能错误地移动batch或band轴。

- 完整保留原复数系数的幅值和相位，不得只对幅度谱做逆变换。
- 子带包含正负值是正常的，禁止取abs、clip到[0,1]、转uint8、阈值清零或丢弃负数。
- 不对每个子带单独做min-max归一化，也不对16带分别加均值偏置。
- 本任务交付的`bands`是原始实值子带，直接求和就能重构`raw_dpm_01`。如后续需要标准化，应另开显式变换并保存可逆参数，不在本阶段偷偷加入。
- 所有子带保持原始H×W分辨率，不做下采样、裁频压缩或VAE编码。
- 数学上信息完整；浮点运算允许下述容差，不宣称浮点结果逐位相等。

9. 必须运行的数值验收

以下验证直接服务于分带与无损重构，不能用肉眼观察代替：

A. 数据划分：场景数、TX数、样本数、训练与验证/测试无交集；验证与测试交集恰好为指定50个场景及其全部TX。

B. Mask结构：16个非空mask，二值、互斥、全覆盖；同q不拆分。把mask转回未shift频谱后，用索引(u,v)->((-u)%H,(-v)%W)验证共轭闭合。包含四角和Nyquist位置。

C. 使用float64 GT与complex128 FFT，在[0,1]输入尺度上：

```text
max_abs_imaginary_part <= 1e-10
max_abs(sum(bands_float64) - gt_float64) <= 1e-10
```

D. 实际Dataset返回或缓存回读的float32子带，采用float32求和后与真实GT比较：

```text
max_abs_error <= 1e-6
RMSE <= 1e-7
```

记录最大误差及其sample_id；若失败，诊断实现或精度问题，不通过裁剪重构图或放宽容差掩盖。

E. 验证Parseval能量守恒：空间GT能量、完整频谱能量与16带空间能量之和相符。float64计算对正常非零样本的相对误差应<=1e-10；零能量样本采用绝对误差检查。

F. 验证子带频谱支撑：对子带再FFT，原mask以外的能量仅允许数值误差。用常数图、已知单频正弦图、随机实值图检查DC、共轭、频带顺序和覆盖。

G. 对原始uint8 DPM，验证`rint(255*x_recon)`可恢复原始像素。检查取整后的数值范围并逐像素比较；不能先用clip隐藏错误。
