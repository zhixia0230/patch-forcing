1. 修改范围与保留的研究目标

   当前数据为 [0,1] 单通道 radiomap，分解为一个图像均值和 16 个非 DC 固定径向 FFT 子带。时间方向为 t=0 对应源噪声，t=1 对应干净数据。模型预测每带速度、每带 log_variance，以及标准化均值变量的速度。

   保留现有 16 带定义、图像尺寸、U-Net 主干、速度与不确定性输出头，以及按不确定性选择容易/困难频带的推理机制。继续使用线性 Flow Matching，继续不输入建筑和 Tx 条件。本次先控制加噪相关变量，优化器和现有损失系数沿用并记录；只有发现相关的一致性错误才一起修复，并单独说明。

   训练时间的随机分配不预先规定低频容易、高频困难；推理阶段仍由模型不确定性决定谁先推进。本次训练采样器不是要替换推理时的难度调度器。

2. 只使用训练集，拟合每个频带的固定 RMS 尺度

   完成固定频带掩码拟合后，使用同一训练集划分和确定性预处理，统计未经频带标准化的原始子带 B[n,k,h,w]：

   s_raw[k] = sqrt(sum_{n,h,w} B[n,k,h,w]^2 / (N_train * H * W))
   s[k] = max(s_raw[k], band_rms_floor)

   默认 band_rms_floor=1e-6，这是原始 [0,1] 图像坐标中的 RMS 下限。保存原始 RMS、最终尺度和触及下限的频带编号。若掩码为空、频点计数为零或统计出现 NaN/Inf，应报出具体错误。

   实施要求：

   - 遍历训练集，分批流式累积平方和，使用 float64 累计，避免把整个数据集装入内存。
   - 除以真实累计的样本/像素数，不能把每批均值不加权地平均；不能用“每张图 RMS 的平均”代替上述总体二阶矩。
   - 统计输入必须是原始子带；禁止对已经除过尺度的子带再次拟合尺度。
   - 不使用验证集或测试集拟合任何尺度，不根据当前验证图的真实 RMS 调节噪声。
   - 最终是 16 个固定数，不是每张图 16 个动态数，也不随训练迭代更新。
   - 默认完整训练集统计。小子集只能用于明确标记的调试统计，不得静默用于正式配置。
   - 保存训练划分清单/哈希、掩码哈希、图像尺寸、频带数量、统计样本数、预处理标识与方案版本，防止复用错误缓存。
   - 多进程训练只拟合一次并广播，或者正确归约无重复的统计；不要因为各 rank 重复遍历而误报样本数。

3. 在标准化频带坐标中训练与积分

   数据转换为：

   Z[k] = B[k] / s[k]

   B 和 Z 的张量形状均为 [batch,16,H,W]，广播尺度可以保存为 [1,16,1,1]。它表示训练集上的每带典型 RMS 接近 1，并不强制每个样本 RMS=1。

   重构为：

   B_hat[k] = s[k] * Z_hat[k]
   X_hat = mean_pixel + sum_k B_hat[k]

   如果均值状态 m 使用标准化表示，应先执行：

   mean_pixel = mean_center + mean_scale * m

   接口必须明确区分标准化均值和像素均值，避免重复还原或漏还原。

   如果已有 normalize_bands / normalization_scale，检查它的实际定义后复用或扩展；不要只开一个布尔开关就假定符合上述统计。原始 FFT 投影 P_k 应保持为纯频率投影，不应夹带 RMS 标准化。FFT 与统计使用合适的浮点精度，必要时在混合精度上下文外执行。

   RMS 标准化不等于 min-max 归一化。不要将 Z、含噪状态或预测速度裁剪到 [0,1] / [-1,1]。只在明确的图像展示入口处理显示范围，定量评价保留原始输出和越界信息。

4. 保留单位 RMS 尺度的带限高斯源噪声，避免重复缩放

   对每个通道独立生成白噪声 g_k，执行：

   epsilon_k = P_k(g_k) * sqrt(H*W/N_k)

   N_k 是该带掩码的频点数。复用现有正确的 band_limited_noise(equalize_rms=True) 实现。该式使空间平方 RMS 的期望约为 1；尤其低频带自由度少，单次实现的 RMS 不一定等于 1。

   epsilon 与 Z 在同一训练坐标中使用。因此：

   - 不再把 epsilon 除以 s[k]。
   - 不再给 epsilon 额外乘一个 0.05 一类的共同缩小系数。
   - 不按每次噪声实际 RMS 强制归一成 1，以免改变高斯源分布。
   - 不关闭带限投影或按频点数补偿，并用普通全频 randn 冒充带限源噪声。

   在原始 B 坐标中，这等价于源噪声 s[k]*epsilon_k。它实现了按训练集典型频带幅值确定加噪尺度。

5. 线性插值、速度与不确定性目标全部使用新坐标

   z_t[k] = (1-t[k]) * epsilon[k] + t[k] * Z[k]
   target_velocity[k] = Z[k] - epsilon[k]

   预测速度仍投影回对应频带。每带训练误差为：

   e_z[k] = mean_hw((predicted_velocity[k]-target_velocity[k])^2)

   不确定性 NLL 沿用当前形式，但其误差目标换成上述标准化坐标误差：

   L_unc = 0.5 * mean(exp(-log_variance) * stopgrad(e_z) + log_variance)

   保留当前稳定化和损失权重作为受控实验起点，明确日志中的 log_variance 现在描述标准化速度残差。不要沿用旧 checkpoint 的不确定性校准结论。

   同时记录原始频带坐标的误差 e_B[k]=s[k]^2*e_z[k]，用于区分相对恢复能力与对原图的绝对误差贡献。不要把两种误差混成同一指标。

   审查所有 get_interpolants 调用。在本项目的频带模式中，x0 缺省时应调用正确的带限噪声生成器，或者明确要求调用方提供 x0；禁止静默落到全频 torch.randn_like 的旧 fallback。

6. 用“按阶段抽取共享上限”的采样器替换 75% 的 LTG 分支

   每张样本独立抽取阶段，阶段比例默认：

   | 阶段 | 比例 | 共享上限 tau 的范围 |
   |---|---:|---|
   | early | 0.30 | [0.0,0.3) |
   | middle | 0.40 | [0.3,0.8) |
   | late | 0.30 | [0.8,1.0] |

   在所选阶段内均匀抽取 tau，然后逐样本计算：

   width = min(max_time_gap, tau * gap_fraction)
   u[k] ~ Uniform(0,1), k=1,...,16
   t[k] = tau - width * u[k]

   默认 max_time_gap=0.15，gap_fraction=0.5。使用 batch 向量化实现，输出 t 的形状为 [batch,16]。每张样本有自己的阶段与 tau；不要让整个 batch 只共用一个阶段或一个 tau。

   示例：

   | tau | width | 各带时间范围 |
   |---:|---:|---|
   | 0.20 | 0.10 | [0.10,0.20] |
   | 0.55 | 0.15 | [0.40,0.55] |
   | 0.90 | 0.15 | [0.75,0.90] |

   必须满足 0<=t[k]<=tau<=1。tau 是上界，不必恰好等于 max(t)。同一张样本内，各带时间不同，但不会突破本样本的清晰程度上限。

   时间抽样与当前 GT 内容独立。不根据当前图像哪个带更强或更容易来选择其阶段和 t；实际幅值/SNR 只用于离线统计与调参诊断。使 RNG 可复现，按项目规范处理 seed、rank 和恢复训练状态。

   新模式不再叠加原 LTG 的 loc/scale/std。保留旧采样器作为显式 legacy 对照模式，配置中只启用一种主采样器。

7. 另外 25% 保留 DualLoop 时间状态覆盖，并按阶段分层抽取

   保留 dual_ratio=0.25，主采样器比例为 0.75。每张样本独立选择分支。

   先检查现有 DualLoop 占用时间采样器。复用与实际积分器一致的时间组合，包括同步边界以及容易带领先、困难带逐步追赶的内部状态。默认外层 50 步、内部 4 步、容易带分位比例 0.4 沿用现有配置。

   这个分支也按 early/middle/late=0.30/0.40/0.30 分层抽取。分层按模型实际访问的时间向量 max(t) 所属区间判断，区间定义同上，t=1 归 late。可以先按阶段筛选合法的外层/内部位置再抽取，避免无界拒绝采样。时间组合还要匹配实际容易带数量和更新规则；不能只生成 16 个互相独立的随机时间，然后称为 DualLoop 状态。

   若某配置下某阶段没有合法访问位置，应给出明确错误或可解释的配置提示，不得静默改变比例。共享上限分支中的阶段由 tau 定义，DualLoop 分支中的阶段由 max(t) 定义，因此同时报告配置阶段占比与实际 max(t) 直方图，不声称两者必然完全相同。

   训练中模拟时间组合不需要提前运行完整生成轨迹，不需要使用 GT 推断频带难度。复用时间几何及原有合法的频带选择模拟即可；这只是访问状态覆盖，不宣称精确复现学习后采样器的状态分布。

8. 均值时间与推理状态保持一致

   继续使用现有训练集 mean_center、mean_scale。均值源噪声为标准高斯，均值时间保持 t_mu=max_k(t[k])；使用该时间构造含噪标准化均值，禁止将干净 GT 均值直接送给模型。

   训练、验证、单步预测、Euler、DualLoop 都以 Z 作为频带状态、以标准化 m 作为均值状态。完整生成从同一个单位 RMS 带限噪声源初始化 Z_state，并从标准高斯初始化 m_state；直到重构/显示时才还原物理尺度。

   检查 DualLoop 每次模型调用前的 state 与 band_time 是否对应、mean_state 与 mean_time 是否对应。按实际时间增量积分，不能推进了状态却继续输入旧时间。若维持 t_mu=max(t)，均值的实际积分时间增量也必须与该规则一致，包括没有任何容易带的边界情况。发现既有相关 bug 时修复并给出明确记录。

   训练时的共享上限规则仅负责抽取训练状态，不在推理时强行把整张图限制在某个低时间上限。推理仍从 0 推进到 1，并由不确定性决定各带如何推进。

9. 增加能够判断加噪是否合理的诊断

   在有限、固定的训练诊断子集上统计，不参与反向传播：

   - 每带 s_raw、s、原始 RMS 与标准化 RMS。
   - 源噪声每带平方 RMS 的统计，考虑低频带随机波动。
   - 分支比例、阶段比例、tau、max(t)、min(t)、各带时间直方图。
   - 每带混合后的信号 RMS=t*RMS(Z)，噪声 RMS=(1-t)*RMS(epsilon)。
   - 实际 SNR_dB=20*log10(signal_RMS/noise_RMS)，这是幅度比的 dB 表示。
   - 按阶段统计每张图最大的 SNR，检查 early 中是否经常出现非常清晰的带；按阶段与频带记录重建误差。

   处理零信号、t=0、t=1 等边界：指标可以标记正负无穷/单独计数，或仅为显示采用可记录的数值保护；不要为了计算日志修改真实状态或时间。

   固定 RMS 只能匹配训练集典型尺度。共享时间上限控制名义信噪比，不保证每张图的实际 SNR 都相同，也不保证不同频带的信息量完全可比。实际 SNR 是诊断指标，不替代不确定性难度头。不得通过逐样本使用 GT RMS 重设噪声来假装实现了严格一致。

10. 同步更新单步重建验证与评估口径

   对验证图：先使用保存的固定尺度得到 Z，按配置生成 z_t，调用一次网络得到 v_hat，计算：

   Z_hat[k] = z_t[k] + (1-t[k]) * v_hat[k]
   m_hat = m_t + (1-t_mu) * predicted_mean_velocity
   X_hat = mean_center + mean_scale*m_hat + sum_k s[k]*Z_hat[k]

   分时间/实际噪声水平报告对应 RMSE、SSIM 和分带误差；保存含噪输入、预测、GT 的固定显示范围对比。完整多步生成诊断仍可保留。

   新旧配置相同 t 并不代表相同污染程度。区分“各自训练分布上的诊断”与“公平的固定噪声恢复对比”。后者要使用明确匹配的物理污染过程/SNR、正确对应各模型的时间和输入表示；不能只因为新方案同 t 的输入更干净，就宣称模型本身改善。

12. 完成必要检查后交付实现结果

   验证真实风险，避免只检查函数是否存在：

   - 原图→原始频带→标准化→乘回尺度→重构，在 float32 下误差应接近数值精度，例如最大绝对误差约 1e-5 或更小；解释平台相关容差。
   - 尺度只由训练划分拟合，缓存元数据不匹配时不能误用；保存再加载后的尺度/掩码/模型输出一致。
   - 噪声与预测速度只在对应频带，投影保持正确；每带噪声的总体二阶矩与理论相符，不断言每次样本 RMS 都恰为 1。
   - 共享上限与时间范围成立；分支和阶段频率在合理随机误差内；同种子复现。
   - DualLoop 时间组合确实对应实际模型访问位置，状态/时间一致，包括均值。
   - 用精确目标速度代替网络预测时，单步端点还原能恢复原始 Z 和均值；这检查坐标/系数，不作为模型性能结果。
   - 在小 batch 上执行一次有限值训练检查、单步重建及短 Euler/DualLoop 采样，确认无 NaN/Inf、形状和反标准化正确。
