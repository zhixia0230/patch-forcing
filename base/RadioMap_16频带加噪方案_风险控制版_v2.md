# RadioMap 16 频带加噪方案：风险控制版 v2

日期：2026-09-27。适用任务：给定建筑、TX 等推理时可获得的条件，从噪声生成 radiomap。表示为独立空间均值与 16 个非 DC 径向 FFT 频带，每带保持 256×256 空间尺寸。

这是一套可供首轮受控训练的方案。频带几何和噪声/时间的数值覆盖已检查，模型训练与生成质量尚未验证，不能保证优于原方法。

与前一方案的关系：保留固定训练尺度、带限谱整形高斯源和线性 Flow Matching 路径；把原先 20% 起步 / 60% 异步 / 20% 精修，细化为 20% 起步 / 20% 共同推进 / 40% 异步协作 / 20% 精修。时间采样改用下文的共同时间上限 C 和噪信幅度比倍数，替代旧的 dB 上限区间。两套时间表不要叠加使用。

1. **先明确每项设计负责什么。**

|风险|设计|能够做到的事|仍需验证的事|
|---|---|---|---|
|弱频带被绝对幅度很大的噪声淹没|每带使用训练集固定尺度 s_k|在总体意义上校准信号与噪声尺度|单张图仍有真实幅值变化|
|噪声包含该频带之外的变化|带限高斯源，预测速度也投影|源、训练状态和积分更新保持在本带|网络是否学到真实频带的非高斯分布|
|高频带内部能量分配不合理|固定参考功率谱与均匀谱混合|匹配参考二阶频谱形状，保留所有带内方向|谱整形是否比带内等功率源更有效|
|总有干净频带可供模型依赖|整图共同时间上限，保留全高噪样本|起步训练不提供时间上接近干净的频带|低自由度噪声偶然很小导致的实际 SNR 尾部|
|异步训练漏掉共同推进的中间状态|20% 近同步、全时间范围分支|给进度接近的状态明确训练占比|实际采样轨迹的联合状态覆盖|
|模型没学会使用跨带上下文|40% 随机宽度的异步分支|训练不同进度频带之间的信息利用|生成上下文的错误是否会传播|
|噪声过强或过弱的比例失衡|分支统计实际 SNR，保留起步/中段/精修|发现采样设计偏差|最优分支比例必须由开发集确定|

不能把“噪声合适”理解为“每个时刻都能看清目标”。从纯噪声出发是任务的一部分。不能只通过去掉高噪样本来降低训练误差。

2. **固定表示与尺度。**

对训练目标 x，先计算空间均值 μ，再对 x−μ 做正交归一化 FFT 分解：

\[
B_k=\mathcal F^{-1}(M_k\mathcal F(x-\mu)),\qquad
x=\mu+\sum_{k=0}^{15} B_k.
\]

频带编号使用 0–15。每带零 DC，包含正值与负值，不做逐图 min-max，不压到 [0,1] 或 [−1,1]，不裁剪频带值。

\[
s_k=\sqrt{\mathbb E_{\rm train}\operatorname{mean}_{h,w}B_k^2},\qquad Z_k=B_k/s_k.
\]

3. **构造每带的噪声。**

令 R 为上传的固定 reference_spectrum，M_k 为频带掩码，N_k 为带内频点数：

\[
p_k(f)=\frac{M_k(f)R(f)}{\sum_f M_k(f)R(f)},\qquad
\tilde p_k(f)=0.1\frac{M_k(f)}{N_k}+0.9p_k(f).
\]

每张样本抽实数高斯白噪声 g∼N(0,I)，使用正交 FFT：

\[
\epsilon_k=\operatorname{Re}\mathcal F^{-1}
\left[\sqrt{HW\tilde p_k}\,\mathcal F(g)\right].
\]

实现要求：

- 上传掩码和参考谱是 fftshift 布局；用普通 fft2/ifft2 时先 ifftshift，不能错位相乘。
- 频谱权重需实数、非负、满足共轭对称；在构建缓存时对正负频率位置做对称平均，再归一化。
- g 可以是一张 `[B,1,H,W]` 白噪声图，由互不重叠的 16 个滤波器生成各带噪声。互相正交的高斯频率分量独立；这与把同一张未滤波噪声复制 16 遍不同。
- 10% 均匀功率底座保证所有带内方向都有噪声，不把低能频点删除。ρ=0.9 是首轮实验设置，ρ=0 是必要的带内等功率对照。
- R 是“每张图归一化 AC 功率谱的平均”，不是原始频带协方差的精确估计。这里匹配的是该固定参考谱。
- 不把每次生成的 ε 除以它本次的 RMS。那会改变高斯源分布，尤其影响仅有 4 个实自由度的低频带。

得到 ε_k∼N(0,C_k)：是具有空间相关性的带限高斯场，不再是像素独立的白噪声。每个像素的边缘方差为 1；总体 E[RMS(ε_k)²]=1，单张噪声 RMS 可以波动。原始坐标噪声为 s_k ε_k，像素边缘标准差为 s_k。

这不会让噪声拥有真实高频带的尖峰、重尾或建筑边缘。那些高阶统计仍需模型学习。

4. **用共同时间上限和相对差距分配 16 个 t。**

每张图先抽一种模式，再抽共同上限 C。抽一个该图允许的差距宽度 A，各频带独立抽 a_k∼U(0,A)：

\[
r_k=2^{a_k},\qquad
t_k=\frac{C}{C+(1-C)r_k}.
\]

于是 0<t_k≤C<1，同一频带共享一个 t_k，不同频带的 t_k 在连续分布下几乎必然不同。分支、C、A 和 a_k 都与目标频带内容、真实误差及频带编号独立。

这个公式的意义是：上限 C 确定整组最多能清晰到什么程度；r_k 只在这个上限以下，把某些频带的噪声相对信号再放大一些。

\[
\frac{1-t_k}{t_k}=r_k\frac{1-C}{C}.
\]

|模式|图级抽样概率|C 的连续分布|A 的设置|目的|
|---|---:|---|---|---|
|起步|20%|U(0,0.2)|1|所有 t≤0.2，学习没有清晰频带提示时起步|
|共同推进|20%|U(0,1)|1|覆盖整个生成过程中的进度接近状态|
|异步协作|40%|U(0.2,0.95)|每张图抽 U(0,5)|同时覆盖小差距、中差距与较大差距|
|精修|20%|U(0.9,1)|1|所有 t≥0.81818，学习接近完成时的修正|

这些模式在整个训练期间混合采样，不是四个先后训练阶段，更不是只使用四个时间点。每次前向都会重新抽取连续的时间向量。除理论端点外，整个 (0,1) 都可以取到；浮点实现需防止精确的 0 和 1。

A=1 时，噪信幅度比之间最多差 2 倍，参考 SNR 跨度最多约 6.02 dB；A≤5 时最多差 32 倍，跨度不超过约 30.10 dB。异步分支的 A 随机，避免每个异步样本都被强制拉出很大的差距。

例如 C=0.8，r 分别为 1、2、8，则 t 分别约为 0.800、0.667、0.333。这只演示公式，不把频带编号固定分配到其中某档。

5. **制作模型训练样本，使用同一份噪声定义目标。**

\[
Z_{k,t_k}=t_kZ_k+(1-t_k)\epsilon_k,\qquad
u_k=Z_k-\epsilon_k.
\]

|张量|形状|含义|
|---|---|---|
|干净频带 Z|[B,16,H,W]|训练集固定尺度下的目标|
|源噪声 ε|[B,16,H,W]|每带对应的高斯源|
|时间 t|[B,16]|每图每带一个标量|
|加噪频带 Z_t|[B,16,H,W]|模型的主要输入|
|条件 c|依现有条件编码器|建筑、TX 等推理可获得的信息|
|速度目标 u / 预测速度 v|[B,16,H,W]|归一化频带坐标中的速度|
|logvar|[B,16]|每带预测误差尺度的对数|

模型必须获得完整的 16 维时间向量或等价的逐带时间嵌入；只给一个平均 t 不够。同一频带内部只共享混合系数，不共享某个相同的噪声数值。

原始频带坐标下同一公式为 B_{k,t}=t_k B_k+(1−t_k)s_k ε_k。加噪分量的像素边缘标准差是 (1−t_k)s_k；t=0.5 时，band 0 约为 0.04664，band 15 约为 0.02053。

6. **训练损失与频带约束。**

先将预测速度投影回对应频带：

\[
v_k=P_k(v_{k,raw})=\operatorname{Re}\mathcal F^{-1}[M_k\mathcal F(v_{k,raw})].
\]

\[
e_k^2=\operatorname{mean}_{h,w}(v_k-u_k)^2,\quad
L_{flow}=\mathbb E_{B,k}e_k^2.
\]

每带在标准化坐标中等权平均。不按频点数 N_k 再加权，不用不确定性权重把“难带”的速度监督自动压低。这样低能频带不会仅因原始绝对幅值小而几乎得不到监督。

误差尺度头可用：

\[
L_{unc}=\frac12\mathbb E_{B,k}
[\ell_k+\operatorname{stopgrad}(e_k^2)e^{-\ell_k}].
\]

初始总损失：L=L_flow+L_mean+0.01 L_unc。均值损失也在其固定标准化坐标中计算；权重 1、0.01 是初值，需记录三项损失及生成效果。实现时先对 logvar 做数值范围保护再 exp，避免溢出，初始化 logvar=0；首轮可使用范围 [−12,8]，若大量输出饱和要检查误差分布和设置，不能当作可靠置信度。

这里的 L_unc 是每带平均误差尺度的校准目标，不是 65,536 个独立像素的精确联合高斯似然。带内像素相关，logvar 也不是最终 radiomap 质量保证。detach 阻断对误差项的反向传播，但不隔离共享骨干从不确定性分支收到的梯度。

7. **独立均值必须避免成为额外的真实上下文。**

采用上传统计中的固定数值：

\[
Z_\mu=(\mu-0.27602527060913873)/0.07821975390838161.
\]

抽独立标量 ε_μ∼N(0,1)，令 t_μ=mean_k(t_k)，构造 Z_{μ,t} 和 u_μ=Z_μ−ε_μ。

本版具体选择：均值状态只输入均值头，不输入频带去噪骨干。频带特征 F=backbone(Z_t,t,c)，频带速度与 logvar 从 F 预测；均值头读取 pool(F)、Z_{μ,t}、t_μ 和条件。均值信息不得经 token、卷积输入或交叉注意力反馈进 F。

这是单向使用：均值预测可以参考频带特征，频带预测不读取真值或加噪均值。其目的在于避免一个偶然很干净的均值标量成为额外提示。推理仍需生成均值，不能填入真实 μ。均值头也需要时间嵌入。

如果采用让均值参与频带交互的其他架构，必须重新评估全部 17 个单元的联合干净上下文概率；不能沿用本文 16 带的统计。

8. **首轮推理必须与训练源及时间范围一致。**

- 初始频带状态就是同一定义的 ε，16 个 t 都从 0 出发；均值从独立 N(0,1) 出发。训练和推理使用同一份 masks、s、R、ρ 与 FFT 规范。
- 逐带更新 Z_k←Z_k+Δt_k v_k。投影后的 v_k 零 DC 且带限；必要时以数值容差检查状态。不要每一步重新抽噪声。
- 均值用 Δt_μ=mean_k(Δt_k) 更新，故 t_μ 始终与训练定义一致。
- t=0/1 处的 odds 公式有奇点，端点需显式处理；它们是理论起终点。首步和末步的数值误差必须在完整生成中检查。
- 先用固定共同时间轨迹作生成基线，再评估不确定性自适应轨迹；近同步分支覆盖共同时间轨迹附近，但有限模型误差仍存在。
- 自适应不能依赖真值误差，也不能固定低频先走。先验证 logvar 与每带归一化误差的关系。

首轮保守限制用 q_k=t_k/(1−t_k) 表示：起步与末段 max(q)/min(q)≤2；中段暂设≤8，低于训练允许的最大 32。max(t)<0.2 或 max(t)>0.95 时用 2；中段用 8。max(t) 到 0.95 时先暂停领先带，让其余带追到满足比例 2，再进入末段。所有 q 都为 0 的初态作为特例；接近终点也显式处理，不通过给零时间随意加大常数来掩盖跨度。

这只是防止过大跨度的必要限制，不等于证明训练/推理联合分布匹配，也不是完成版最优自适应积分器。首轮不允许一带 t=0.9、另一带 t=0.1：它们的 q 比为 81，超过训练最大范围。

每次完整采样记录整条时间向量、跨度、是否触及限制，以及各阶段生成误差。若自适应比固定轨迹更差，优先检查时间组合、置信度校准和积分误差，再决定训练修改。

最终恢复：x_hat=μ_hat+Σ s_k Z_hat_k。先记录未裁剪结果的误差和频带能量；若应用需要将最终图限制到 [0,1]，作为单独后处理记录，不能在中间频带状态上裁剪。

9. **如何检测和处理噪声过多、干净上下文过多。**

实际信噪比只用于离线统计与验证：

\[
\mathrm{SNR}_{j,k}=20\log_{10}\frac{t_k}{1-t_k}
+20\log_{10}\frac{\mathrm{RMS}(Z_{j,k})}{\mathrm{RMS}(\epsilon_{j,k})}.
\]

共同上限 C 限制参考 SNR，不给逐样本实际 SNR 作硬保证。尤其低频带仅有少量自由度，噪声幅值的随机波动更大。不要为了保证某个样本的 SNR 而利用它的 GT 调整噪声。

首轮可采用以下开发检查规则；阈值是工程初值，不是理论最优边界：

|发现的问题|下一步动作|
|---|---|
|起步分支超过 1% 的样本出现任一带实际 SNR>0 dB|用独立噪声与开发数据复核；若确认，起步 C_max 从 0.20 调到 0.15，其他分支暂不动|
|异步分支中 SNR<−10 dB 占比超过 50%，或中等区间 [−10,10] 占比低于 40%|检查源尺度和投影；若正确，把 A 的上限从 5 缩到 4，并同步收紧推理跨度|
|训练误差低，但从纯噪声生成明显差|检查是否有真实均值/频带作为条件、源是否一致、全部 t 的注入与积分；不能直接归因于训练轮数|
|高噪区单样本速度误差较高，但完整生成改善|不因这一项误差较高就删掉高噪训练；它含有条件不确定性|
|固定轨迹正常，自适应显著退化|先收紧领先幅度，检查 logvar 校准和积分步长；暂不盲目减少所有噪声|
|高频能量和尾部持续不足|对比 ρ=0 与 0.9、每带误差及条件注入，不能默认“高频噪声大”就是唯一原因|

所有阈值先看每带和每分支，再看总体。改变一个参数后保持架构、训练预算、种子集合和验证样本一致。不要根据最终测试集挑选参数。

模型自己生成的清晰上下文仍可能错误；本方案只能减少时间覆盖失配和源分布失配，不能从加噪公式上彻底消除该问题。必须以闭环生成检验。若进一步训练自生成上下文，应单独设计自条件/蒸馏目标；不要直接用模型输出替换 Z_t 的一部分，却继续宣称原 u=Z−ε 是该新状态的正确 Flow Matching 配对标签。

11. **最小必要对照与验收。**

12. **时间采样参考实现。**

下列 NumPy 实现可作为移植到 PyTorch 的逻辑参考。生产实现使用设备端随机数，并将随机数状态纳入复现实验。这里返回 float64；转 float32 前后检查端点与形状。

```python
import numpy as np

def sample_band_times(batch_size, rng, bands=16):
    mode = rng.choice(4, size=batch_size, p=[0.2, 0.2, 0.4, 0.2])
    low = np.array([0.0, 0.0, 0.2, 0.9])
    high = np.array([0.2, 1.0, 0.95, 1.0])
    cap = rng.uniform(low[mode], high[mode])
    # 防止有限精度恰好取端点；不读取目标图来裁剪时间。
    cap = np.clip(cap, 1e-6, 1.0 - 1e-6)
    width = np.ones(batch_size)
    mixed = (mode == 2)
    width[mixed] = rng.uniform(0.0, 5.0, size=mixed.sum())
    exponent = rng.random((batch_size, bands)) * width[:, None]
    ratio = np.exp2(exponent)
    t = cap[:, None] / (cap[:, None] + (1.0-cap[:, None]) * ratio)
    return t, mode, cap, width
```
